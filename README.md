# 끼리끼리 nextjs 정리본

코드를 next기준으로 실행할 수 있게 나눈 구조입니다.

## 구조

```txt
src/
  main.tsx
  App.tsx
  pages/
    Home.tsx
    PostDetail.tsx
  components/
    PostCard.tsx
    ParticipationDialog.tsx
    MatchSuccessDialog.tsx
```

## 실행

```bash
npm install
npm run dev
```

터미널에서 안내하는 localhost 주소를 열면 됩니다.
